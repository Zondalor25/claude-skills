# slidelab-business-text

Личная лаборатория: **презентации** и **анализ бизнес-текстов** (отчёты, брифы, договоры, письма, тексты сайтов).

## Структура

| Папка | Что внутри |
|---|---|
| `skills/` | Скиллы Claude для работы с презентациями и графиками (копии из открытых репозиториев) |
| `business-text-analysis/` | Место для собственных скиллов и промптов по разбору бизнес-текстов (пока пусто) |
| `SOURCES.md` | Откуда взято, под какой лицензией |

## Скиллы в `skills/`

- **pptx-toolkit** — создание и аудит .pptx, чек-лист сдачи, оценка плотности слайдов
- **chart** — графики (bar/line/area/pie/doughnut) из чисел
- **academic-pptx-skill** — академические презентации (конференции, защиты)
- **frontend-slides** — анимированные HTML-презентации, конвертация из PowerPoint

## Как подключить скилл к Claude

```bash
cp -R skills/<имя-скилла> ~/.claude/skills/
```

После этого Claude Code подхватит скилл в новой сессии.
